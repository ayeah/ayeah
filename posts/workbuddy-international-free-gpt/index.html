WorkBuddy 是什么？

🌍 国际版最大卖点：不用翻墙用 GPT-5

国内开发者想用 GPT-5、Gemini，通常面临三道坎：

  1. 翻墙 —— 门槛最高的一步
  2. 海外手机号注册 —— OpenAI/Google 不接受中国号码
  3. 海外信用卡付款 —— 国内 Visa/Master 部分被封

WorkBuddy 国际版直接绕过这三道坎：

  • ✅ 只需 Google 或 GitHub 账号登录（OAuth 授权，秒注册）
  • ✅ 内置 GPT-5、Gemini 模型，无需单独注册 OpenAI 账号
  • ✅ 免费版直接送积分，零成本上手
  • ✅ 首次登录需要国际网络环境，之后大部分功能可直连

功能上，阉割了项目、网盘等云端服务，其他功能基本都保留了，也有中英文界面可选。

🔬 实测：Deep Research 功能

国际版首页主推的 Deep Research（深度研究）是最让人惊喜的功能。

你给它一个研究主题，它会：

  1. 自动拆解搜索路径 —— 规划多个搜索方向
  2. 交叉验证信源 —— 从多个来源对比信息，排除错误数据
  3. 生成结构化报告 —— 包含结论、竞品矩阵、策略建议

官方说法：15 分钟内从研究到结论，交付一份完整报告。

实测体验

给它丢了一个主题：“2026 年 AI Agent 行业趋势分析”，它自动拆解了六个方向：

  • Anthropic vs OpenAI 的 ARR 对比
  • 北美四大云 AI Capex 数据
  • 多模态 + 推理时计算 + Agent 编排趋势
  • 中国大模型从规模竞争到价值变现
  • 全球监管三分化趋势
  • Agent 生产渗透率风险

每个方向都引用了具体数据源，最后给出一句话结论和六个关键拐点。免费积分跑 1-2 次完全没问题。

🤔 国际版 vs 国内版：怎么选？

选国际版的理由

  • ✅ 想用 GPT-5 / Gemini，但不想折腾翻墙、海外信用卡
  • ✅ 需要英文场景的深度推理和代码生成
  • ✅ 免费额度够日常轻度使用

选国内版的理由

  • ✅ 日常办公为主，国产模型完全够用
  • ✅ 想白嫖——签到领积分，免费额度更大
  • ✅ 需要企业微信、QQ、腾讯文档深度集成
  • ✅ 模型种类多（13 款），按场景精细选型更省积分
  • ✅ 不想碰任何国际网络环境

最优解：双持

日常轻量任务用国内版（做任务领积分），深度攻坚切国际版。

两个版本账号互不通用，客户端也分开安装，但界面和操作逻辑基本一致，切换成本几乎为零。
