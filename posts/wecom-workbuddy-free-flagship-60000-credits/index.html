大羊毛！企业赠送workbuddy旗舰版，60000积分！

企业微信认证企业可免费领 WorkBuddy 企业旗舰版 30 个席位、1 个月试用，含 60000 积分。这笔账怎么算、怎么领、有哪些坑，一次说清。

先说结论：公司做过企业微信认证，现在能白拿 WorkBuddy 企业旗舰版 30 个席位，用一个月，还带 60000 积分。旗舰版官方价 198 元/席/月，30 席一个月就是 5940 元。不是抽奖，认证企业就能领。

真正值得看的不是席位，是企业微信放出的 AI 开放能力。8 月 18 日，企业微信面向所有规模企业开放 CLI 和 MCP 接口，覆盖消息、邮件、文档、待办、日程、会议、微盘。以前 AI 只能告诉你文档在哪，现在能自己读纪要、拆待办、派人、发消息。人员权限和 AI 操作权限分开配，关键动作要人工审批，授权到期回收，全程留痕。WorkBuddy、DeepSeek Harness、MiniMax Code 都能接。

WorkBuddy 这边叫企微助理集成，本质是用企业微信远程遥控你电脑上的 WorkBuddy。群里 @ 机器人丢任务，它在本地跑完把结果发回聊天窗口，还能跨设备接续。前提是电脑装着 WorkBuddy 4.6.4 以上、开机运行，它不跑在云端。推荐长连接模式：企业微信后台建智能机器人，选 API 模式、用长连接，复制 Bot ID 和 Secret，到 WorkBuddy 设置里的企微助理集成填上注册，不用公网 IP。

60000 积分来自旗舰版基础权益：2000 积分/席/月 × 30 席 = 60000，进企业共享池，全团队共用，管理员可按人分配。

积分用来计量模型调用、文件处理和自动化任务，不同模型、不同复杂度扣得不一样。30 人的团队跑一个月，写方案周报、读表做分析、从知识库定位资料、跑定时任务，基本够用。旗舰版还自带办公套件：腾讯文档、乐享知识库、腾讯设计 Ardot、腾讯网盘每席 50G。

怎么领：确认企业认证 → 找官方活动入口提交信息 → 分配 30 个席位 → 开跑。两个坑：积分有有效期，到期清零不补发；席位领了不用等于白领，第一天就落到具体人头上，给个真实任务。认证是门槛，个人号、没认证的主体领不到，个人开发者可以去看 WorkBuddy 面向个人的免费额度。

试用当评估，别当白嫖。一个月跑通一两个真实场景，算出省了多少人力，再决定要不要续。

席位数量、时长、积分额度以官方活动页实时规则为准。
