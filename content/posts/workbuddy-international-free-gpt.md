## 📝 注册教程：3 分钟从零到上手

### 步骤 1：访问官网

打开 <https://workbuddy.ai/invite?code=KUWWXDW4>

### 步骤 2：选择登录方式

- **Google 账号**（推荐，最快）
- **GitHub 账号**

点击对应图标，完成 OAuth 授权即可。系统自动创建账号，新用户获得 **350 免费积分**。

### 步骤 3：下载安装

| 平台      | 文件                            |
| ------- | ----------------------------- |
| Windows | `WorkBuddySetup.exe`（~150 MB） |
| macOS   | `WorkBuddy.dmg`（~150 MB）      |
| Linux   | `.deb` / `.rpm`               |

安装后首次启动，选择主题和语言（推荐中文简体），登录账号。

### 步骤 4（可选）：安装 CLI 命令行工具

```bash
npm install -g @tencent-ai/codebuddy-code
```

安装后运行 `codebuddy`，选择 **"Log in via International Site"** 完成授权。

### 步骤 5：验证安装

在对话框输入：

```
帮我写一个 TypeScript 的 todo 应用，使用 React + TailwindCSS
```

如果模型正常返回代码——恭喜，你已经成功用上了 GPT-5！

## 🤔 国际版 vs 国内版：怎么选？

### 选国际版的理由

- ✅ 想用 GPT-5 / Gemini，但不想折腾翻墙、海外信用卡
- ✅ 需要英文场景的深度推理和代码生成
- ✅ 免费额度够日常轻度使用

### 选国内版的理由

- ✅ 日常办公为主，国产模型完全够用
- ✅ 想白嫖——签到领积分，免费额度更大
- ✅ 需要企业微信、QQ、腾讯文档深度集成
- ✅ 模型种类多（13 款），按场景精细选型更省积分
- ✅ 不想碰任何国际网络环境

### 最优解：双持

> 日常轻量任务用**国内版**（做任务领积分），深度攻坚切**国际版**。

两个版本账号互不通用，客户端也分开安装，但界面和操作逻辑基本一致，切换成本几乎为零。
